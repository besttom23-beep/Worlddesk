# Working on The World Desk

Read `SKILL.md` before changing this website. Keep content maintenance in the JSON catalog and feed configuration where possible. Preserve source attribution, accurate freshness labels, free-access distinctions, relative asset paths, and keyboard/reduced-motion behavior.

Use the scripts documented in `package.json`. Run `npm run check` and `npm run build` for meaningful changes; use `npm run refresh` when feed behavior changes. Do not publish or change a repository's visibility beyond the user's current request.
